# Saarthi AI MVP

## Integrated Student Roadmap & Citizen Government Scheme Eligibility Matcher

This MVP document is based on the uploaded synopsis and prior project planning conversation.

## Vision

Build one AI-powered platform that helps students discover personalized academic roadmaps and helps citizens discover government schemes and scholarships based on eligibility.

## Core Modules

1. Student Roadmap Engine
2. Government Scheme Eligibility Matcher
3. Scholarship Matcher
4. AI Copilot (RAG + Rule Engine)
5. Document Readiness Assistant
6. Notifications & Deadline Tracker

## Target Users

- Students
- Citizens
- Farmers
- Women
- Job seekers
- Senior citizens

## Problem Statement

Information about education, scholarships, and welfare schemes is fragmented across multiple portals. Users struggle to know what they are eligible for and what to do next.

## MVP Features

### Student Roadmap
- Semester roadmap
- Skill gap analysis
- Certifications
- Internship tracker
- Progress tracker

### Government Scheme Matcher
- Profile-based eligibility questionnaire
- Rule-based matching
- Benefit summary
- Required documents
- Official application links

### Scholarship Matcher
- NSP and state scholarship discovery
- Deadline reminders
- Eligibility explanation

### AI Assistant
- RAG chatbot
- Career guidance
- Scheme explanation
- Document guidance

### Document Assistant
- OCR upload
- Missing document detection
- Readiness checklist

## Tech Stack

Frontend: Next.js, React, TypeScript, Tailwind CSS, Shadcn UI

Backend: Node.js, Express.js, TypeScript, Prisma

AI: Python, FastAPI, LangChain, Vector DB

Database: PostgreSQL, MongoDB, Redis

Deployment: Docker, Vercel, AWS S3

## Architecture

Frontend → Backend APIs → AI Engine → Database → Government APIs

## User Flow

Sign up → Build profile → AI roadmap → Eligibility matching → Notifications → Progress tracking
